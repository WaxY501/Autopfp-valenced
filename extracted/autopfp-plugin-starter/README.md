# AutoPFP Rotator — Valenced plugin starter


This is the initial source scaffold for the AutoPFP Rotator plugin.

## Planned behavior
- Search images from the user's theme/query automatically
- Cache candidate images, randomly choose one, and avoid repeats
- Automatically download, square-crop, resize, and compress
- Rotate on a configurable interval
- Start/stop, Change Now, and persistent settings

## Current status (0.1.0 starter)
- Valenced manifest and JS plugin skeleton included
- Persistent settings structure defined
- Basic settings screen scaffold included
- **Not functional yet:** image search/download pipeline, timer, manual controls, and avatar-update integration

The avatar update action is not implemented until a compatible API method is verified. This starter is not ready to install as a working rotator.

## Development
Use the official Valenced plugin template/CLI to bundle this plugin. This ZIP is source scaffolding, not a compiled installable plugin ZIP.
